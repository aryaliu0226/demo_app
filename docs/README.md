# 项目文档

本文档目录用于沉淀“宠友，有宠”项目的产品、技术、数据、接口和部署说明。

## 文档目录

- [项目概览](./overview.md)：项目描述、目标用户、核心能力、业务边界。
- [产品需求文档](./prd.md)：产品目标、功能范围、用户流程、验收标准、迭代建议。
- [技术架构](./architecture.md)：技术栈、应用分层、认证、上传、AI、缓存与安全设计。
- [项目结构](./structure.md)：目录结构、路由结构、模块职责、代码组织约定。
- [数据模型](./database.md)：Prisma 模型、核心实体、关系说明、计数字段与数据风险。
- [接口说明](./api.md)：页面路由、API Routes、Server Actions、关键入参和权限。
- [部署说明](./deployment.md)：本地运行、环境变量、数据库迁移、构建与部署注意事项。

## 维护建议

- 产品功能变更优先更新 [产品需求文档](./prd.md)。
- 新增接口或修改入参后同步更新 [接口说明](./api.md)。
- Prisma Schema 或迁移变化后同步更新 [数据模型](./database.md)。
- 新增目录、模块迁移或分层调整后同步更新 [项目结构](./structure.md)。
- 环境变量、外部服务和部署方式变化后同步更新 [部署说明](./deployment.md)。
